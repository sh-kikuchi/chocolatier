# 要件定義書

## 概要

自分の思い出や日常の瞬間を写真として投稿し、コメントを添えて個人アルバムのように保存できます。写真のアップロードやコメント入力など、さまざまな便利な機能を簡単に使えます。

構成は以下のとおりです：

- **バックエンド**：Django（REST API）
- **フロントエンド**：React
- **対象環境**：PCブラウザ向け

## 機能要件
- ユーザー登録
- ログイン
- ログアウト
- スナップの一覧表示
- スナップの新規登録
- スナップの削除
- スナップの更新
- ファイルの新規登録
- ファイルの削除

## 非機能要件
- デバイス：PC想定（初期開発ではレスポンシブデザインを考慮に入れない）
- CORS設定：React（別ポート）からのAPIアクセスを許可
- 画像保存：ローカル
- 認証方式：トークンベース（JWT）
- 画像サイズ制限：最大 5MB / 枚
- 表示言語：日本語対応
  
## 使用技術
- Django（バックエンド）
- React（フロントエンド）
- SQLite（初期DB）

## 使用ツール・サービス
- バージョン管理： GitHub
- APIのテスト： Postman
- Python仮想環境：venv
- 開発用エディタ： VSCode
- VSCodeの拡張機能
  - Open API
  - Markdown All in One

## 備考
- 初期バージョンでは「いいね」や「フォロー」機能は搭載しません。
- 投稿へのコメント機能は省略予定（コメントはSnapに付随する形で投稿時にのみ入力）。
