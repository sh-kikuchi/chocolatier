## 2. API

| ID | メソッド・URL | 内容 | 認証 | CSRF |
|---|---|---|---|---|
| API-001 | `GET /csrf/` | `csrftoken` Cookie を配る | 不要 | ― |
| API-002 | `POST /token/` | ログイン（Cookie に access・refresh をセット） | 不要 | 不要 |
| API-003 | `POST /token/refresh/` | access を取り直す | refresh Cookie | 不要 |
| API-004 | `POST /logout/` | 認証 Cookie を消す | 不要 | 不要 |
| API-005 | `GET /chocolatier_api/user-info/` | ログイン中の利用者 | 必要 | ― |
| API-006 | `POST /chocolatier_api/signup/` | 利用者の登録 | **管理者** | 必要 |
| API-007 | `GET /chocolatier_api/snap/` | 自分のスナップ一覧（`?tag=`・`?cursor=`） | 必要 | ― |
| API-008 | `POST /chocolatier_api/snap/create/` | スナップの作成（multipart） | 必要 | 必要 |
| API-009 | `POST /chocolatier_api/snap/download/` | 表示中の画像の Zip | 必要 | 必要 |
| API-010 | `GET /chocolatier_api/snap/{id}/` | スナップの詳細（画面からは使っていない） | 必要 | ― |
| API-011 | `PATCH /chocolatier_api/snap/{id}/` | コメント・タグの更新（PUT は 405） | 必要 | 必要 |
| API-012 | `DELETE /chocolatier_api/snap/{id}/` | スナップの削除（204・本文なし） | 必要 | 必要 |
| API-013 | `GET /chocolatier_api/tags/` | 自分が使っているタグ名 | 必要 | ― |
| API-014 | `GET /media/{path}` | 画像（持ち主だけ。他人・存在しないものは 404） | 必要 | ― |
| SYS-01 | `/admin/` | Django 標準の管理画面（セッション認証） | 管理者 | Django 標準 |

詳しい入出力は [API 定義（OpenAPI）](api/index.yaml)。

## 3. 業務ルール

| ID | ルール | 主な実装 |
|---|---|---|
| BR-001 | スナップと画像は **持ち主だけ** が見る・更新する・削除する。他人の ID は「存在しない」（404）として扱う | `SnapList`・`SnapDetail`・`MediaFileView` |
| BR-002 | 投稿者は、送られた値ではなくログイン中の利用者にする | `SnapCreate.perform_create` |
| BR-003 | 一覧は新しい順に 12 件ずつ。読んでいる途中で増減しても、重複・抜けが起きない | `SnapCursorPagination` |
| BR-004 | 画像は jpg・jpeg・png・gif・webp、5MB 以下、中身が画像として読めること | `SnapCreateSerializer` |
| BR-005 | コメントは任意、1000 文字以内 | `SnapCreateSerializer`・`SnapUpdateSerializer` |
| BR-006 | タグは前後の空白を除き、空と重複は捨てる。1 つ 30 文字以内、1 スナップ 10 個以内 | `clean_tag_names` |
| BR-007 | 同じ名前のタグは全利用者で 1 つを共有する。絞り込み候補には自分のタグだけを出す。**どのスナップにも付いていないタグは消す** | `TagList`、`services/tags.py` |
| BR-008 | 更新できるのはコメントとタグだけ。タグを送らなければ変えず、空の配列で全部外す | `SnapUpdateSerializer.update` |
| BR-009 | スナップを消すと、画像（DB の行と実ファイル）も消す。**API・管理画面・利用者の削除のどれから消しても同じ** | `signals.py` |
| BR-010 | Zip は表示中のスナップから新しい順に最大 100 件。自分のものだけ。フォルダは 1 つ（タグ名、なければ「すべて」、記号は `_`）。実ファイルがない画像は飛ばし、1 枚もなければ 404 | `SnapZipDownload`、`services/zip.py` |
| BR-011 | 新規作成の画像は送る前に 1:1 に切り抜く。1 辺 1080px を超えたら縮小。gif は png の静止画になる。5MB のチェックは切り抜いた後 | `cropImage.ts`、`SnapshotPage` |
| BR-012 | 利用者の登録は管理者だけ。登録された利用者は一般利用者。**メールアドレスは重複不可**（大文字・小文字の違いも同じ。空は可） | `UserSignup`、`UserSerializer.validate_email` |
| BR-013 | ログインに失敗したとき、ユーザー名とパスワードのどちらが違うかは教えない | `CookieLoginView`、`SignInPage` |
| BR-014 | 認証情報は HttpOnly Cookie。access 60 分・refresh 1 日。access 切れは画面が自動で取り直し、refresh も切れたらサインインし直す | `set_auth_cookies`、`client.ts` |
| BR-015 | ログイン中の更新系の操作には、CSRF トークンが必要 | `enforce_csrf` |
| BR-016 | 画像は `uploads/<元の名前>_<yyyymmddHHMMSS><拡張子>` で保存する（日時は PC の時刻） | `services/files.py` の `save_upload` |
| BR-017 | タグで絞り込み中に、そのタグを持たないスナップを作った・タグを外したときは一覧から外す。選んでいたタグが候補から消えたら「すべて」に戻す | `SnapshotPage.matchesFilter`・`fetchTags` |
| BR-018 | スナップの作成（画像の保存・スナップ・タグ）は 1 つのトランザクション。途中で失敗したら、保存した実ファイルも消す | `SnapCreateSerializer.create` |
| BR-019 | ログイン中の入口は `/snaps`。ログイン中に `/` や `/signin` を開くと `/snaps` に移動する | `GuestRoute` |

## 4. 今の動きを仕様とするもの（調査で確認し、変えないと決めたもの）

| Q | 内容 |
|---|---|
| Q-002 | `/playground` はログインなしで見られる |
| Q-004 | 画像のファイル名の日時は PC の時刻（DB は UTC） |
| Q-005 | 同じ名前の画像を同じ秒に 2 回アップロードすると 500 になる（既知の不具合） |
| Q-006 | Zip の件数エラー（空・101 件以上）は英語で返る |
| Q-016 | playground の「api」ボタンは「Not Found」になる |
| Q-021 | トリミング機能より前の、正方形でない画像はそのまま（一覧では中央を正方形に切って表示） |
