# DB設計（Django側）

## users テーブル

| カラム名      | データ型     | PK | NN | FK | UQ | 備考                                         |
|---------------|--------------|----|----|----|----|----------------------------------------------|
| id            | BIGINT       | ○  | ○  |    |    | ユーザーID（自動採番）                      |
| username      | VARCHAR(255) |    | ○  |    | ○  | Django標準のユーザー名。ログインIDとして使うことが多い。|
| email         | VARCHAR(255) |    | ○  |    | ○  | メールアドレス。一意制約あり。メール認証や通知に使用。|
| password      | VARCHAR(255) |    | ○  |    |    | パスワード。バックエンド側でハッシュ化して保存。|
| user_type     | VARCHAR(10)  |    | ○  |    |    | ユーザー種別。`'general'`, `'creator'`, `'brand'` のいずれか。|
| profile_info  | TEXT         |    |    |    |    | ユーザーのプロフィール自由記述。空欄も可能。|

## snaps テーブル

| カラム名    | データ型     | PK | NN | FK | UQ | 備考                 |
|-------------|--------------|----|----|----|----|----------------------|
| id          | BIGINT       | ○  | ○  |    |    | スナップID           |
| user_id     | BIGINT       |    | ○  | ○  |    | 紐づくユーザーID     |
| file_id     | BIGINT       |    | ○  | ○  |    | 紐づくファイルID     |
| comment     | TEXT         |    |    |    |    | コメント             |
| created_at  | TIMESTAMP    | ○  |    |    |    | 作成日時（自動）     |
| updated_at  | TIMESTAMP    | ○  |    |    |    | 更新日時（自動）     |

## files テーブル

| カラム名    | データ型       | PK | NN | FK | UQ | 備考                     |
|-------------|----------------|----|----|----|----|--------------------------|
| id          | BIGINT         | ○  | ○  |    |    | ファイルID               |
| name        | VARCHAR(255)   | ○  |    |    |    | ファイル名               |
| path        | VARCHAR(500)   | ○  |    |    | ○  | ファイルパス（ユニーク推奨） |
| created_at  | TIMESTAMP      | ○  |    |    |    | 登録日時（自動）         |
| updated_at  | TIMESTAMP      | ○  |    |    |    | 更新日時（自動）         |
