## 1\. 背景

| # | 課題 | 該当箇所 |
|---|---|---|
| 1 | 一覧のパネルは 200×200 の正方形だが、画像をそのまま縦横 200px に引き伸ばしているため、縦長・横長の写真がつぶれて見える | `SnapshotPanel.module.css` |
| 2 | 写真のどの部分を見せるかをユーザーが選べない | — |

## 2\. 決定事項

| 項目 | 方針 |
|---|---|
| 加工のタイミング | **アップロード前**（ブラウザ内）。サーバーには切り抜いた後の画像だけを送る |
| 比率 | 1:1 に固定 |
| 操作 | ドラッグで位置、スライダー（またはホイール）で拡大縮小 |
| 作る方法 | ライブラリ `react-easy-crop` で「どこを切るか」を選ばせ、切り抜き自体は `<canvas>` で自前で行う |
| 出力サイズ | 長辺の上限を 1080px にする（大きすぎる写真は縮小） |
| 出力形式 | 元が jpg / jpeg / webp → 同じ形式。png → png。**gif → png**（canvas はアニメーションを扱えないため、1 コマ目の静止画になる） |
| ファイル名 | 元の名前のまま、拡張子だけ出力形式に合わせる（`photo.gif` → `photo.png`） |
| サイズチェックの順番 | 拡張子は**選んだとき**、5MB のチェックは**切り抜いた後**に行う（スマホの 8MB の写真も、切り抜き・縮小すれば投稿できるようにするため） |
| Backend | 変更なし（今までどおり画像として受け取ってチェックする） |
| 更新（既存の Snap） | 対象外。今も更新では画像を変えられないため |

### ライブラリを使う理由

| 方法 | 良い点 | 悪い点 |
|---|---|---|
| `react-easy-crop`（採用） | ドラッグ・拡大縮小・スマホのピンチ操作が揃っている。軽い（依存なし） | 依存が 1 つ増える |
| すべて自前（canvas＋マウスイベント） | 仕組みを全部理解できる | タッチ操作や、はみ出し防止の計算が大変で、時間がかかる |

ライブラリは「どの範囲を切るか（ピクセル座標）」を返すだけなので、**切り抜く処理（canvas）は自前で書いて仕組みを学べる**。

### 計画からの変更点

| 項目 | 計画 | 実際 | 理由 |
|---|---|---|---|
| ライブラリのバージョン | `react-easy-crop` 5.x | 6.2.5 | インストール時点の最新。API（`Cropper` / `Area` / `Point`）は 5.x と同じ |
| 出力サイズ | 長辺の上限 1080px | **1 辺**の上限 1080px（`MAX_CROP_SIZE`） | 1:1 なので長辺＝1 辺 |
| 「決定」の props 名 | `onCropComplete(file)` | `onConfirm(file)` | `react-easy-crop` にも `onCropComplete`（範囲が決まるたびに呼ばれる）があり、名前がかぶって紛らわしいため |
| 一時的な URL の作り方 | 記載なし（既存の `previewUrl` と同じ `useMemo` ＋ `useEffect`） | **作るのも破棄するのも同じ `useEffect` の中**。値は `useState` に入れる | StrictMode では開発中に useEffect が「実行 → 後片付け → 実行」と 2 回動く。`useMemo` は作り直さないので、破棄済みの URL が残って画像が表示されなかった（M3 で発覚） |
| `SnapshotPage` の `previewUrl` | 変更なし | 上と同じ形に直した。同じ後片付けの `useEffect` が 2 か所に重複していたので 1 つにした | 同じ不具合があった（開発中は新規作成のプレビューが出ていなかった） |
| プレビューの下 | 記載なし | 「画像を選び直す」ボタンを追加 | トリミングをやり直したいときに、モーダルを閉じずに戻れるようにするため |
| 「決定」前に保存したとき | 記載なし | 「画像の範囲を「決定」してください」と表示 | 「画像を選択してください」だと、選んだのに何が足りないのかわからないため |
| ImageCropper のエラー | 記載なし | 切り抜きに失敗したら、部品の中にエラーを表示 | 壊れた画像などで canvas の処理が失敗することがあるため |

## 3\. 今の作りで必要な準備

| # | 準備 | 理由 |

| P4 | `SnapshotPanel` に `object-fit: cover` を付ける | 今までの（正方形でない）画像がつぶれて見えるのを直す。これだけで課題 1 は既存の画像でも解消する |
