## 6\. 注意点・残っていること

| 項目 | 内容 |
|---|---|
| 画像の表示とログインの有効期限 | 画像の取得にも access\_token（60 分）が要る。長く放置したあとは、一覧の読み込みなどで画面が自動でトークンを取り直すまで、新しい画像の取得が 401 になることがある。すでに表示している画像はそのまま |
| メールの重複チェックの範囲 | 登録 API だけ。管理画面から利用者を作るときは、Django 標準のフォームなので重複を止めない |
| 使われていないタグの片付け | マイグレーション 0003 は、まだ当てていない環境では `python manage.py migrate` で動く。この PC の DB には 2026-11-19 に当てた（8 個削除。DB のコピーは取ってある） |
| 要確認（回答待ち） | Q-007（ヘッダーのアプリ名の移動先の回答）、Q-013 のパスワードの強さのチェック、Q-015 の定義のない URL の扱い |
| 見送り | スナップと画像の 1 対 1 を DB の制約（OneToOneField）にすること。構造の変更が必要なので、今回は後片付けの処理だけで原則を守る形にした |
