## 2. 新しい案件を足すとき
1. [_template.md](_template.md) をコピーして、`09_〇〇.md` のように番号と名前を付ける
2. 上の一覧に 1 行足す（状態は「計画」「対応中」「ブラウザ確認待ち」「完了」など）
3. 進めながら、案件のファイルを直接書き換える（マイルストーンの完了・確認結果・計画からの変更点）
4. 実装を変えたら、[02_設計](../02_設計/01_アーキテクチャ.md) と [03_開発](../03_開発/00_開発ガイド.md) の関係する文書も直す
